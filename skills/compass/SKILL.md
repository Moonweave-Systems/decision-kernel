# Compass

Use at a handoff, after scope expands, or before a consequential action when the current work may diverge from the original request.

1. Establish the baseline from the supplied argument, an explicitly named brief, or the original request visible in the current conversation. Include later user corrections and accepted scope changes. If the intended baseline is unavailable, ask for it. Read a transcript only if the user supplies its exact path or the current session identity is verified.
2. Compare the baseline with the current result, work in progress, and next action. Point to concrete evidence for any missing deliverable, changed constraint, or unauthorized expansion. An agreed change supersedes the original wording.
3. Report the goal, current alignment, and the smallest correction in three short lines. Say when the available evidence cannot establish alignment. Apply a correction when the active task already authorizes it.
